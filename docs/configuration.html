Configuration Reference

All environment variables and configuration keys for every Tarcinapp component.

Naming conventions: EPS uses UPPER_SNAKE_CASE env vars directly. Gateway uses Spring Boot property style: app.some.thing → env var APP_SOME_THING. Indexed arrays: APP_KINDALIASPATHS_0_ALIAS=books. Orchestrator uses MicroProfile Config: property.key → PROPERTY_KEY.

Header Alignment: EPS default is X-Request-ID (capital D). Gateway default is X-Request-Id (lowercase d). These must match — set APP_REQUESTID=X-Request-ID on the gateway or change EPS to match.

EPS — Uniqueness Constraints

VariableDescription
ENTITY_UNIQUENESSUniqueness rule(s) for entities
LIST_UNIQUENESSUniqueness rule(s) for lists
RELATION_UNIQUENESSUniqueness for relations
ENTITY_REACTION_UNIQUENESSUniqueness for entity reactions
LIST_REACTION_UNIQUENESSUniqueness for list reactions

Format: a filter template string using where[field]=${field} interpolation. ${field} is replaced with the value from the record being created. Multiple rules are comma-separated — a record must not violate any rule.

# Entities unique by kind + slug + creator (per-user uniqueness)
ENTITY_UNIQUENESS="where[_kind]=${_kind}&where[_slug]=${_slug}&where[_createdBy]=${_createdBy}"

# Multiple rules: above rule + publisher names globally unique
ENTITY_UNIQUENESS="where[_kind]=${_kind}&where[_slug]=${_slug}&where[_createdBy]=${_createdBy},where[_kind]=publisher&where[_slug]=${_slug}"

# One rating per user per book
ENTITY_REACTION_UNIQUENESS="where[_kind]=rating&where[_entityId]=${_entityId}&sets[owners][userIds]=${_createdBy}"

EPS — Record Limits

Record limits restrict how many records a user can create within a given scope. Configured as a JSON array:

# Max 3 wishlists per user
LIST_RECORD_LIMITS='[{"scope":"where[_kind]=wishlist","limit":3}]'

# Max 10 books globally
ENTITY_RECORD_LIMITS='[{"scope":"where[_kind]=book","limit":10,"global":true}]'

# Multiple rules
ENTITY_RECORD_LIMITS='[
  {"scope":"where[_kind]=book","limit":50},
  {"scope":"where[_kind]=book","limit":200,"global":true}
]'

Gateway — Kind Alias Paths

Each kind alias is a set of indexed environment variables sharing the same index N (0-based). All variables for one alias must use the same index.

VariableRequiredDescription
APP_KINDALIASPATHS_N_ALIAS✓ YesURL path segment (plural). Example: books
APP_KINDALIASPATHS_N_NAME✓ Yes_kind value to inject. Example: book
APP_KINDALIASPATHS_N_SCHEMANoJSON Schema string for request body validation
APP_KINDALIASPATHS_N_HIERARCHYALIASNoChild route path segment. Example: chapters → /books/{id}/chapters
APP_KINDALIASPATHS_N_HIERARCHYNAMENo_kind value for children. Example: chapter
APP_KINDALIASPATHS_N_RATELIMITER_REPLENISHRATENoRate limiter replenish rate override for this alias
APP_KINDALIASPATHS_N_RATELIMITER_BURSTCAPACITYNoRate limiter burst capacity override
APP_KINDALIASPATHS_N_MAXREQUESTSIZENoMax request body size override
APP_KINDALIASPATHS_N_DISABLEDNoSet to true to disable this alias's routes entirely
 
# Example: books alias with chapters hierarchy
APP_KINDALIASPATHS_0_ALIAS=books
APP_KINDALIASPATHS_0_NAME=book
APP_KINDALIASPATHS_0_SCHEMA={"type":"object","required":["author"]}
APP_KINDALIASPATHS_0_HIERARCHYALIAS=chapters
APP_KINDALIASPATHS_0_HIERARCHYNAME=chapter
APP_KINDALIASPATHS_0_RATELIMITER_REPLENISHRATE=10
APP_KINDALIASPATHS_0_RATELIMITER_BURSTCAPACITY=20

Gateway — Saved Queries

Named query presets. Called via ?q=name. Configured as indexed arrays:

APP_QUERIES_0_NAME=my
APP_QUERIES_0_QUERY=sets[owners][userIds]=${sub}

APP_QUERIES_1_NAME=popular
APP_QUERIES_1_QUERY=sets[actives]=true&filter[order]=viewCount%20DESC&filter[limit]=20

The ${sub} placeholder is replaced at query time with the JWT sub claim.

Gateway — Field Sets

Named field projections. Called via ?fieldset=name:

APP_FIELDSETS_0_NAME=summary
APP_FIELDSETS_0_FIELDS=_id,_name,_kind,_visibility,author,genre

APP_FIELDSETS_0_NAME=full
APP_FIELDSETS_0_FIELDS=*
